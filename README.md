# Погнали — MVP 1.5

## Что изменилось

MVP 1.5 не добавляет новых продуктовых сущностей. Он закрывает обнаруженный UX-пробел: кнопка «Редактировать профиль» теперь действительно открывает форму и сохраняет изменения через API.

Можно изменить:
- имя;
- город;
- «О себе».

Дата рождения и другие приватные данные по-прежнему не показываются публично.

## Главная задача сейчас

Не добавлять новые функции, пока не пройден ручной тест на человеке, который заранее не знает интерфейс.

### Сценарий теста
1. Открыть приложение как гость.
2. Найти интересное событие.
3. Открыть событие.
4. Найти действие «ПОЙДУ».
5. Войти.
6. Вернуться к событию.
7. Открыть чат.
8. Отправить сообщение.
9. Открыть профиль.
10. Понять, как изменить профиль.
11. Найти «Создать» и попробовать создать событие.

Во время теста не подсказывать. Записывать каждую фразу вида «а это что?», «куда нажать?», «почему?», «как мне…?».

## Запуск

Backend:
```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

PostgreSQL:
```bash
docker compose up -d
```

Flutter:
```bash
cd mobile
flutter pub get
flutter run
```

Для Android emulator API по умолчанию: `http://10.0.2.2:8000`.
