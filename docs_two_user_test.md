# Два пользователя: ручной smoke-test

## Подготовка

1. Запусти PostgreSQL: `docker compose up -d`
2. Запусти API: `cd backend && uvicorn app.main:app --reload`
3. В отдельном терминале: `cd backend && python scripts/seed_two_users.py`
4. Сохрани два токена из вывода.

## Проверка

**Пользователь 1 — организатор**
- открой `GET /events`;
- открой тестовое событие;
- проверь себя в участниках;
- отправь сообщение в чат.

**Пользователь 2 — участник**
- открой `GET /events`;
- выполни `POST /events/{EVENT_ID}/join`;
- получи `GET /events/{EVENT_ID}/participants`;
- получи `GET /events/{EVENT_ID}/messages`;
- отправь сообщение.

Ожидаемый результат: оба пользователя видят событие, оба находятся в участниках и видят сообщения друг друга.

## Безопасность

- запрос сообщений без участия должен возвращать 403;
- блокировка/жалоба требуют авторизации;
- блокировка одного пользователя не должна влиять на другого.
